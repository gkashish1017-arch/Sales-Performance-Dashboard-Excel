# 📊 Sales Performance Dashboard | Microsoft Excel

An interactive **Sales Performance Dashboard** built using Microsoft Excel to analyze sales, orders, customers, products, regions, categories, and customer segments.

## 📌 Project Overview

This project analyzes **9,800 sales transaction records** and transforms raw sales data into an interactive business dashboard.

The objective was to identify sales trends, understand regional and category performance, identify top-performing products, and provide key business KPIs through an easy-to-use dashboard.

---

## 🎯 Business Objectives

* Analyze overall sales performance
* Track monthly sales trends
* Compare sales across regions and categories
* Identify top-performing products and customers
* Analyze customer segment performance
* Monitor key business KPIs
* Provide interactive filtering through slicers
* Generate actionable business insights

---

* Customer Name
* Category
* Sub-Category
* Product Name
* Region
* Segment
* Ship Mode

## 🧹 Data Cleaning & Preparation

Before creating the dashboard, I performed several data quality checks:

* Verified the dataset structure and column data types
* Checked total transaction records
* Checked duplicate Row IDs
* Checked missing values in important fields
* Verified Order ID, Customer ID, and Product ID
* Validated Order Date and Ship Date fields
* Checked Sales values
* Checked Postal Code completeness
* Created helper columns for unique Order and Customer counts
